## 🎨 **Design System**

### **Colors**:
- **Primary**: #3B82F6 (Blue)
- **Background**: #FFFFFF (White)
- **Secondary**: #F9FAFB (Light Gray)
- **Text**: #374151 (Dark Gray)
- **Accent Orange**: #FEF3C7
- **Accent Pink**: #FCE7F3

### **Typography**:
- **Headers**: 18px, Bold
- **Body Text**: 13-16px, Medium
- **Captions**: 10-12px, Regular
- **Consistent Font Weights**: 400, 500, 600, 700

### **Spacing**:
- **Container Padding**: 16px
- **Section Margins**: 20-24px
- **Card Padding**: 12-16px
- **Icon Sizes**: 20-24px

### **Shadows & Elevation**:
- **Cards**: Subtle shadow with 0.1 opacity
- **Navigation**: Elevated with 8px shadow radius
- **Active States**: Enhanced shadows for interaction

---

## 📱 **Responsive Design**

### **Product Grid**:
- **2 Columns**: 48% width each with 4% gap
- **Aspect Ratio**: Optimized for product images
- **Touch Targets**: Minimum 44px for accessibility

### **Category Grid**:
- **5 Columns**: 18% width each (mobile optimized)
- **Circular Icons**: 50px diameter containers
- **Flexible Layout**: Adapts to different screen sizes

### **Navigation**:
- **5 Items**: Equal flex distribution
- **Safe Area**: Proper bottom padding for modern phones
- **Icon Consistency**: 20px icons with 4px spacing
